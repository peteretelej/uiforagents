The quayside instrument

An amber instrument panel: one phosphor hue on warm black, all-mono everything, intensity as hierarchy. Readout strip walls, dot-matrix fills, bracket states, stepped crisp charts, a ticker tape. Built for instrument jobs - tickers, price watchers, machine rooms. Everything below is built from foundation.css alone.

oct 09 2026 · light-dark() tokens, dark lead · one hue, no second color anywhere · hand-authored svg · zero required javascript

01 · design rationale

Ops consoles watch systems; instruments watch quantities. This identity is the terminal on the trading floor or the machine-room wall: it reports, it does not chat. One amber hue does all the work - brightness is hierarchy, brackets are the state language, and the type is mono because instruments count.

what makes it espresso-panel
Single hue - every color is amber over warm black; a second hue is the one unforgivable move. Readout walls - the five-cell strip is the signature; values are big, accent, tabular. Bracket states - [ OK ] / [WARN] / [FAIL] as brightness rungs, never colors. Dot-matrix fills - bars and meters are made of visible dots, like real hardware. The tape - a ticker band that reads statically and marquees as decoration.
what stays out
Ops furniture - no severity rails, no log-level facets, no dense tables with sort/filter/pagination. That is night-ops' job. Health dots - readings are bracket rows; LEDs only as meter fills. Warmth - no rounded bento, no soft pills, no encouragement. tally-board owns friendly. Proportional type - no sans anywhere. The ledger's books stay in paper-ledger.

10 · print, modestly

Print forces the light values at the root - nothing is hand-recolored. The tape stops, the cursor dies, chrome drops via .ep-noprint, panels never split across pages, and a folio ships via the @page margin box. Print this page: the wall is the proof.
