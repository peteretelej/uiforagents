Short answer: at today’s learning rates, fermented whey crosses conventional whey on cost between 2027 and 2029, and subsidy exposure is the single biggest swing on either side of that window.[1]

The curve is built from three inputs: published techno-economic baselines for 100 m³ fermenters, announced capacity through 2028, and a 14–18% learning rate observed across microbial protein plants since 2018.[2] Conventional whey holds a fairly flat €4.60–4.90/kg band on EU spot pricing, so the crossover is driven almost entirely by the fermented line.[3]

How the curve is built

The model below reproduces the base case: capex per tonne falls with cumulative capacity, opex follows feedstock and energy, and the fermenter utilisation ramp is the honest unknown. Sensitivity on utilisation is wider than the learning-rate band, which is why the crossover is a window, not a date.

learning-rate.py
def crossover(base_cost, ferm_cost, learning=0.16, years=range(2026, 2031)):
    for year in years:
        scale = 1 - learning  # capacity compounds annually, 14-18% band
        ferm_cost *= scale
        if ferm_cost <= base_cost:
            return year, ferm_cost
    return None, ferm_cost

# base case: €4.75/kg conventional, €9.10/kg fermented (2026)

What makes it ivory-desk

  • Warm oat-ivory paper #F6F4EE, shifted deliberately from the category’s ivory so it reads desk, not clone.
  • Messages are flat, full-width blocks with tint differentiation — never bubbles, never floating cards.
  • Newsreader speaks: empty-state headlines, voice lines, answer headings, never below 20px. Inter works: everything interactive.
  • IBM Plex Mono reports: tool names, model IDs, token counts, citation markers, timestamps.
  • One clay accent in two steps — text-safe #A8431F, graphic #C65A33 — plus four status hues with fixed jobs.
  • Flat and calm: no glass, no gradients, no glows; the only soft ring is the composer focus ring, which is a job.

Decisions

  1. Oat, not ivory-white. The base leans warm and granular; the category leader’s exact ivory was measured and avoided.
  2. Two-step clay. --accent (#C65A33) is graphic only — caret, meters, quote rules; --accent-ink (#A8431F) carries text and fills, and both pass contrast on every ground.
  3. Serif is a role, not a theme. Exactly one serif voice: assistant statements, headlines, answer headings. Body and chrome are Inter; machine output is mono.
  4. Documents, not bubbles. Turns are full-width flat blocks; the user turn takes the one-step tint; nothing floats.
  5. Status has a grammar. Moss done, ochre running/waiting, brick failed, slate blue informational — always glyph + label + color, never color alone.
  6. Light only. Warm paper is the identity; a dark variant is out of scope for v1.
  7. Motion is flavor. A pulsing caret, quiet fades under 250ms, smooth disclosures — all die under reduced-motion.
