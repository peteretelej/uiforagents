Section 1Design rationale

reading-room exists so an agent building a reading artifact (an article, a briefing, a catch-up guide, a report) never improvises the reading experience again. The decisions below are extracted from a proven long-form page, not invented.

Paper, not white. The light theme sits on warm paper (--bg) with pure-white card surfaces. The dark theme is a warm near-black with a green cast, not a flat grey. Both schemes share the same hue family, so switching themes feels like dimming the same room, not visiting another site.

Serif carries the reading; sans carries the chrome. Body copy is a Charter-led serif stack at 18px/1.7 with a 70ch measure. UI chrome (kickers, meta rows, TOC, table headers, chips, labels) is the system sans in small, letterspaced uppercase. Code is the system mono.

One accent, spent on action. Green (--accent) marks links, the active TOC entry, and section eyebrows. Amber and red exist only as semantic status (warn, danger) in callouts and chips. Nothing decorative gets a color.

The override model. The whole file lives in @layer foundation, so any unlayered page CSS wins without !important. Theme switching needs no attribute dance: tokens use light-dark() and re-resolve against color-scheme on html.

Section 3Typography

The lede opens a section: one size up from body, muted, still serif.

Body paragraphs hold a 70ch measure (--measure) at 18px/1.7. Bold is reserved for scan anchors, not emphasis decoration. Inline code() sits on the wash with a hairline border. Below 900px the base size steps down to 17px.

Third-level headings

h3 inside a section is 1.15rem serif with generous top margin. Section h2 is 1.65rem with a hairline top rule; the numbered eyebrow (.rr-secnum) above it is optional:

  • Serif for everything the reader reads at length.
  • Sans for everything the reader scans: kickers, labels, meta.
  • Uppercase only via CSS on sans micro-labels, never typed in caps.

Section 4Callouts

Callouts interrupt the prose with a left border and a tinted fill. Three intensities exist; use the mildest one that tells the truth.

Note

The neutral callout: surface fill, accent left border, accent-ink label. For context, definitions, and side commentary.

Caution

The warn callout: amber. For trade-offs, gotchas, and things that bite later if ignored.

Stop

The danger callout: red. For irreversibility and real risk. If a page has several of these, the page is arguing with itself.

Section 9How this page was built

  • One stylesheet. The entire <style> block above is foundation.css pasted in verbatim. No other CSS exists on this page, so the demo renders identically pasted into a single file or served next to a linked copy.
  • The theme toggle is the only JavaScript. It flips color-scheme on html, and every light-dark() token re-resolves. Without JS the page renders fully in the OS-preferred scheme. color-scheme must stay on html: root-level tokens only re-resolve against the root's scheme.
  • No attributes, no per-theme blocks. There is no data-theme attribute anywhere and no duplicated dark token list. Dark mode is half of every token.
  • Responsive and printable. Below 900px the TOC sidebar becomes a <details> element and the shell collapses to one column. Print styles drop the chrome, force light ink, and keep cards and callouts from splitting across pages.
  • Overridable by construction. Everything is layered; page CSS written after (or outside) the foundation wins without !important. Brand by swapping tokens, not by restyling components.
