Colophon · what makes it dither-lab

The 1-bit workshop, not an ops console

dither-lab is a showcase identity for creative and dev-tool surfaces. It shares a genre with terminal identities and shares nothing with their grammar:

  • Blue-black #101318 canvas - never neutral near-black, never a single-hue phosphor screen.
  • Four-color rotational bit-palette: each section carries exactly one bit-color (amber → cyan → green → magenta, top-down), set with a .bit-* modifier. Never a rainbow page, never a monochrome one.
  • Press Start 2P is for wordmarks and badges only, at 8px multiples with a 16px floor - never body text. Pixelify Sans carries headings, Space Grotesk carries prose, VT323 speaks only in large readouts.
  • Dither is a pattern overlay: 2px checkers via repeating-conic-gradient at 4-6% alpha as section backdrops. It approximates, never computes.
  • Scanlines exist on the hero only, at 3% alpha.
  • Motion is stepped: steps() marquees, blink cursors, hover jumps. No smooth eases; everything honors prefers-reduced-motion.
  • Radius 0 and 2px borders are laws. Depth is pattern and border, never blur; the one shadow is a 12px bit-color glow on a section's primary element.
Colophon · decisions

Calls this demo makes

  • Dark is the only theme. The blue-black canvas is the identity; print re-inks to paper values instead of deriving a screen light scheme.
  • Magenta does double duty as the error hue - the one fixed semantic assignment in the palette. It never decorates.
  • The console speaks VT323 at 20px: machine output reads as CRT readout, while prose stays in Space Grotesk.
  • The marquee runs steps(4) per loop on purpose: it flips like a split-flap board instead of gliding.
  • The empty palette slot is a real state, not lorem: it names the void and offers the next action.

Colophon · do / don't

Keep it in the workshop

Do
  • Assign one bit-color per section, decided top-down.
  • Keep bitmap type at 8px multiples: 16, 24, 32.
  • Use the dither band as a section backdrop at 4-6% alpha.
  • Stepped hovers: 2px jumps, no easing.
  • One glow per section, on the primary element.
Don't
  • Never mix two bit-colors inside one component (the four-color underline bar is the only blend).
  • Never set body text in Press Start 2P or VT323.
  • No CRT curvature, fake boot screens, or web3 neon.
  • No shadows or blur; depth is pattern and border.
  • No dense ops tables - that is graphite-terminal's job.
