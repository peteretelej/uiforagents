The Almanac collects one year of built work and the arguments behind it. The brief asked for a book that a student could navigate without a table of contents and a partner could quote without opening it twice. The answer was structural, not decorative: a strict twelve-column grid, three type sizes, and one rule weight.

Every spread states its own coordinates. Section numbers run in the outer margin in mono caps; photographs sit inside hairline frames at two fixed aspect ratios; body text holds a single measure from first page to last. Red appears exactly once per chapter: on the figure that carries the argument.

A student navigates it without a table of contents; a partner quotes it without opening it twice.

The brief's test, restated as the design's pass condition.

What makes it weissraum

  • Everything flush left, ragged right. Nothing is ever centered or justified.
  • Hairlines are the only surface treatment: 1px var(--line), full-width, everywhere.
  • Flat. No shadows, no gradients, no rounded corners. Radius is 0px as a law.
  • One red accent, only when it has a job: links, active nav, at most one highlighted figure per view.
  • Hierarchy from size jumps, not color: display is at least 3× body (44/64/96px steps).
  • Uppercase mono micro-labels, index numbers 01–06, and typographic arrows → ↗. Never icon fonts.

Decisions

  1. Neutral-cold paper. #FCFCFA leans cold on purpose; warm off-white is a different identity in this catalogue.
  2. Open-source grotesks. Archivo for display, Inter for body, IBM Plex Mono for micro-labels, loaded via @fontsource when the surface allows; the stacks degrade to the Helvetica/Arial class with zero webfonts.
  3. Poster scale. Display steps 44/64/96px with tight tracking (−0.02em); the display-to-body ratio never drops under 3×.
  4. Light is canonical. The near-black scheme is the derived alternative via light-dark(); the toggle flips color-scheme on the root.
  5. Motion is flavor. 150–250ms ease-out: underlines draw in, arrows nudge 4px, sections rise 8px on reveal. Everything honors reduced-motion.
  6. No photography in this demo by design. The plate is the image slot drawn typographically; swap in framed photography at fixed aspect ratios when assets exist.

Do / Don't

Do

  • Set headlines flush left at poster scale and let whitespace carry the luxury.
  • Use hairlines as full-width rules; one rule weight, one color.
  • Number everything wayfinding-shaped: nav, sections, index rows, figures.
  • Keep exactly one accent moment per view, and make it earn its place.

Don't

  • Don't center, justify, or round anything. Radius stays 0px.
  • Don't add shadows, gradients, second accents, icon fonts, or emoji.
  • Don't shrink the type scale; if display is under 3× body, the page stops being weissraum.
  • Don't build dashboards or data UI with it; this is a portfolio system, not an ops console.
